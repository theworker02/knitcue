# knitcue

Knit identifiers and cue tokens for idempotent workflows.

**Site:** https://theworker02.github.io/knitcue/

## Install / run

```bash
git clone https://github.com/theworker02/knitcue.git
cd knitcue
node src/cli.js
node --test
```
